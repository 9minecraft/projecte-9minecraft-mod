# ProjectE — Transmute Unwanted Blocks Into Diamonds

ProjectE 9minecraft Mod adds a complete matter-energy economy to Minecraft. Every item gets an EMC value, which acts like magical money. You can break down blocks you do not need and store their value. Then, you use that stored value to create blocks you actually want. This system changes how you gather resources because everything has a price and can be traded.

Transmutation Table: Place an item inside to learn its recipe permanently and save its EMC value to your character.

## What this build is

An unofficial rebuild of **SinKillerJ**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
